# Violeta Pet — site demonstrativo

Landing page responsiva para pet shop, desenvolvida com HTML5, CSS3 e JavaScript puro.

## Estrutura
- `index.html` — conteúdo e estrutura semântica
- `css/style.css` — identidade visual, layout, responsividade e animações
- `js/script.js` — menu mobile, scroll reveal, navegação ativa e avisos demonstrativos

## Como executar
Abra `index.html` no navegador. Para desenvolvimento, recomenda-se usar a extensão Live Server do VS Code.

## Personalização antes de publicar
1. Substitua nome, endereço, e-mail, telefone e horários fictícios.
2. Atualize os links das redes sociais.
3. Troque os perfis de adoção de demonstração por animais reais, com autorização e informações verificadas.
4. Configure um canal real para receber contatos. O formulário não foi simulado; os links de contato usam e-mail/telefone de exemplo.
5. Revise cada fotografia e o enquadramento final antes de publicar.

## Fotografias
As imagens são carregadas remotamente do domínio `images.unsplash.com`. A licença padrão da Unsplash permite uso gratuito, inclusive comercial, mas não cobre automaticamente direitos de terceiros visíveis na foto (como marcas, obras ou pessoas identificáveis). Confira a licença e os detalhes de cada imagem antes de publicar:
- https://unsplash.com/license
- https://help.unsplash.com/en/articles/2612315-can-i-use-unsplash-images-for-personal-or-commercial-projects

As URLs incluem parâmetros de tamanho/corte para reduzir o peso transferido. Para produção, recomenda-se baixar as imagens aprovadas, gerar versões WebP/AVIF e hospedá-las localmente.
